Öğrenci Bilgi Sistemi
Bu proje, C++ kullanarak basit bir öğrenci bilgi sistemi uygulamasıdır. Uygulama, öğrencilerin bilgilerini kaydetme, listeleme, silme ve arama işlemlerini gerçekleştirebilir.

Özellikler
Yeni Kayıt Ekleme: Öğrencinin adını, ID'sini ve sınav notunu girerek sisteme yeni bir öğrenci ekleyebilirsiniz.
Tüm Listeyi Gösterme: Sistemde kayıtlı olan tüm öğrencilerin bilgilerini listeleyebilirsiniz.
ID'ye Göre Öğrenci Silme: Belirli bir ID'ye sahip öğrenciyi sistemden silebilirsiniz.
Öğrenci Arama: Öğrenciyi ID'sine göre arayıp, bilgilerini görüntüleyebilirsiniz.
Çıkış: Uygulamadan çıkabilirsiniz.


Kullanım
Uygulama çalıştırıldığında, ana menüde çeşitli seçenekler sunulacaktır. Kullanmak istediğiniz işlemi seçmek için ilgili rakamı girin ve Enter tuşuna basın.

Yeni Kayıt Ekle: Öğrenci bilgilerini girin ve kaydedin.
Tüm Listeyi Göster: Kayıtlı tüm öğrencileri listeleyin.
ID'ye Göre Öğrenci Sil: Silmek istediğiniz öğrencinin ID'sini girin.
Öğrenci Ara: ID'ye göre öğrenci araması yapın.
Çıkış: Uygulamadan çıkın.
Dosya Yapısı
main.cpp: Ana program dosyası.
ogrenci.h: Öğrenci sınıfının tanımlandığı başlık dosyası.
ogrenci.cpp: Öğrenci sınıfının metotlarının tanımlandığı kaynak dosyası.

Student Information System
About the Project

This project is a simple Student Information System implemented in C++. It allows users to manage student records by adding new students, listing all students, deleting students by their ID, and searching for students. The system provides a straightforward way to handle student information efficiently and demonstrates basic C++ programming concepts such as classes, file handling, and object-oriented programming.

Features and Usage

Users can add a new record by entering a student’s name, ID, and exam score. All registered students can be listed at any time, and specific students can be searched or deleted using their ID. The application runs through a main menu, where the user selects the desired operation by entering the corresponding number and pressing Enter. Options include adding a new record, displaying all records, deleting a student by ID, searching for a student, and exiting the program.

File Structure

The project consists of three main files: main.cpp, which contains the main program; ogrenci.h, the header file defining the Student class; and ogrenci.cpp, which implements the class methods
